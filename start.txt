# Property & Rental Management Information System (MIS)
# Setup and Execution Instructions

## 1. Prerequisites (Tools to Download)
Before starting, ensure you have the following installed on your Windows machine:
1. Python (3.10 or newer) - https://www.python.org/downloads/
2. Git - https://git-scm.com/download/win
3. XAMPP (for MySQL Database) - https://www.apachefriends.org/download.html
4. GTK3 (Required by WeasyPrint for generating PDFs) - https://github.com/tschoonj/GTK-for-Windows-Runtime-Environment-Installer

## 2. Database Setup (MySQL via XAMPP)
1. Open XAMPP Control Panel.
2. Click "Start" next to MySQL.
3. Click "Admin" next to MySQL to open phpMyAdmin in your browser.
4. Click on "Databases" at the top.
5. Create a new database named exactly: `rental_mis_db`
6. Make sure the collation is set to `utf8mb4_general_ci`.

## 3. Project Configuration
1. Open a terminal in the project root directory.
2. Copy the example environment file to create your own configuration:
   `copy .env.example .env`
3. Open the newly created `.env` file and verify the database credentials. Default XAMPP settings are:
   DB_NAME=rental_mis_db
   DB_USER=root
   DB_PASSWORD=
   DB_HOST=127.0.0.1
   DB_PORT=3306

## 4. Install Dependencies
1. Open a terminal (PowerShell or Command Prompt) in the project root directory.
2. Create a virtual environment:
   `python -m venv venv`
3. Activate the virtual environment:
   `.\venv\Scripts\activate`
4. Install all required Python packages:
   `pip install -r requirements.txt`

## 5. Database Migration & Initialization
With the virtual environment activated, run the following commands to set up the database tables:
1. Apply migrations:
   `python manage.py migrate`
2. Create a superuser (admin account) so you can log in:
   `python manage.py createsuperuser`
   (Follow the prompts to enter an email and password)

## 6. Running the Project
Whenever you want to run the application, open a terminal in the project folder and run:

1. Activate virtual environment (if not already activated):
   `.\venv\Scripts\activate`
2. Start the development server:
   `python manage.py runserver`
3. Open your browser and go to:
   http://127.0.0.1:8000
4. Log in using the superuser credentials you created earlier.
